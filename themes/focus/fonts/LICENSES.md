# Font licences

The faces in this directory are the Latin subsets served by Google Fonts, in woff2.

| Files | Family | Licence |
|---|---|---|
| `Ubuntu-*.woff2` | Ubuntu, by Dalton Maag | Ubuntu Font Licence 1.0, https://ubuntu.com/legal/font-licence |
| `JetBrainsMono.woff2` | JetBrains Mono (variable, 400 to 500 used) | SIL Open Font License 1.1, https://github.com/JetBrains/JetBrainsMono/blob/master/OFL.txt |

Both licences allow redistribution with documents and themes.
